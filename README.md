# Make the coolest art — make.fun coolest-art-01

An 18-year-old Japanese girl, the female version of the prince tyr avatar:
long ponytail hair split half black and half pink, large pink eyes, no
sunglasses, no tattoo anywhere, gold dangling earring. Streetwear: oversized
black hoodie, short denim jeans, black headphones resting around her neck,
plain black high-top sneakers with no logo or text, sucking a pink swirl lollipop, standing
against a dark smoky background. Vertical 9:16 portrait.

The program (`main.py`, Python 3.13 stdlib only) copies the bundled
`coolest.jpg` (576x1024 JPEG, 110,143 bytes) verbatim to
`/output/entry.png`. No network, no clock, no randomness: two runs write
byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
